remember-me

Long-term memory for your AI assistant. It keeps your conversations word for word, builds a map of what was decided, what's open and the rules you've set, and hands it to the assistant every time you come back.

Connect your assistant
  1. Settings → Connectors → Add custom connector.
  2. Name remember-me, URL https://remember-me.fastapicloud.dev/mcp
  3. Connect and sign in (Google, Microsoft, GitHub, Apple or email). That creates your account.
  4. In a chat in your project, say "start memory for this project".

Add to ~/.cursor/mcp.json (or Settings → Tools & MCP):

{ "mcpServers": { "remember-me": { "url": "https://remember-me.fastapicloud.dev/mcp" } } }

Enable it and follow the sign-in prompt.

Command palette → MCP: Add Server → HTTP → paste the URL, or add to mcp.json:

{ "servers": { "remember-me": { "type": "http", "url": "https://remember-me.fastapicloud.dev/mcp" } } }

Start it and sign in. Used by GitHub Copilot's agent mode.

Add to ~/.gemini/settings.json (note httpUrl, not url):

{ "mcpServers": { "remember-me": { "httpUrl": "https://remember-me.fastapicloud.dev/mcp" } } }

Restart the CLI; it opens sign-in in your browser the first time.

    What you get

    • "Where were we?" works in any new chat, on any device.
    • A live map of each project you can browse, rename and tidy.
    • Your rules stick: things you told the assistant once ("never touch production", "British spelling") keep applying.
    • Yours to take with you: download everything as plain files, or keep it only on your own computer.

    For AI assistants setting this up

    If a user asked you to set up remember-me from this page:

    • It's a remote MCP server at https://remember-me.fastapicloud.dev/mcp (streamable HTTP) with OAuth sign-in. Discovery: /.well-known/oauth-protected-resource; Client ID Metadata Documents and dynamic client registration are both supported.
    • Add it wherever your app takes a custom connector or remote MCP server, and let the user sign in.
    • If you call it with your own code, send a User-Agent that names your client (for example my-assistant-connector/1.0). Python's default Python-urllib signature is refused by the host with error 1010.
    • Then call remember_guide and follow it: always pass project, and a stable session name per conversation when saving.
