Connect your assistant

It takes a minute. Signing in creates your account; your memory is then the same in every assistant you connect.

Then, in a chat about one of your projects, say "start memory for this project".

  1. Settings → Connectors → Add custom connector.
  2. Name remember-me, URL https://remember-me.fastapicloud.dev/mcp
  3. Connect and sign in (Google, Microsoft, GitHub, Apple or email). That creates your account.
  4. In a chat in your project, say "start memory for this project".

Command palette → MCP: Add Server → HTTP → paste the URL, or add to mcp.json:

Start it and sign in. Used by GitHub Copilot's agent mode.

Add to ~/.gemini/settings.json (note httpUrl, not url):

What changes

Your assistant stops starting from zero.

"Where were we?" works

Any new chat, on your phone or your laptop, opens with what's going on in the project and where each thread stopped.

Rules stay put

Things you said once, like "never touch production" or "British spelling", keep applying in every chat after.

A map you can see

Browse each project's topics, decisions and open questions, and rename, merge or close them yourself.

Yours to take

Download everything as plain files, delete any of it, or keep a project only on your own computer.

For AI assistants setting this up

If someone sent you here to connect remember-me, this is what you need.

  • It's a remote MCP server at https://remember-me.fastapicloud.dev/mcp (streamable HTTP) with OAuth sign-in. Discovery: /.well-known/oauth-protected-resource. Client ID Metadata Documents and dynamic client registration are both supported.
  • Add it wherever your app takes a custom connector or remote MCP server, and let the user sign in.
  • If you call it with your own code, send a User-Agent that names your client, for example my-assistant-connector/1.0. Python's default Python-urllib is refused by the host with error 1010.
  • Then call remember_guide and follow it. Always pass project, and a stable session name per conversation when saving.
